# CAD Cost Analyzer 2D v2.5 — Platz sparen

## Что изменено

- Приоритет по умолчанию: **минимум израсходованной площади листов** (сначала количество листов, затем общая площадь). Режим «сохранять остатки» больше не включён по умолчанию.
- На стадии построения первичных вариантов включена дополнительная точная координатная доуплотняющая эвристика для автоматической формы листа. Она перемещает детали к контактным позициям, не изменяет их геометрию и принимает итог только если площадь действительно уменьшилась и геометрия валидна.
- Вкладка «Остатки»: отдельный блок для **2 или 3** обрезков по порогу **5 / 7 / 10 %** площади соответствующего листа. Контуры и расположение отображаются на SVG, доступны отдельные DXF и JSON.
- Площадь обрезков рассчитывается по реальным свободным полигонам с учётом ширины реза и фильтра минимальной ширины. Геометрические контуры не служат подтверждением технологической отделимости и зажима заготовки.

## Ограничения

- Глобальная оптимальность в непрерывной 2D nesting-задаче математически **не гарантируется**.
- Глубокая перестановка Engine 2 по-прежнему ограничена диапазоном 2–8 деталей и заданным лимитом поиска; раскладки с большим числом деталей обрабатываются существующим движком.
- Координатное доуплотнение относится к auto-stock; размеры фиксированного листа не меняются.
- Процентный порог применяется к **площади листа**, а не к общей площади свободного материала.
- Проверить CAM-траектории, фиксацию заготовки и отделимость обрезков перед реальной резкой.

## Запуск

`START_WINDOWS.bat` либо `START_LINUX_MAC.sh`. Для проверки: `python -m pytest -q tests/test_material_priority.py`.
